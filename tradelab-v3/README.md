# TradeLab 2 — учебная торговая платформа с роботами

Тренажёр для обучения трейдингу с менторами. Все счета демо, средства виртуальные. Пополнения и вывода реальных денег нет, пометка «ДЕМО» видна на всех страницах.

## Что умеет

### Котировки
- **74 инструмента** в 5 категориях:
  - акции США и Европы;
  - индексы: US500, US100, US30, DE40, UK100, JP225;
  - фьючерсы CME: ES, NQ, YM, RTY, нефть, газ, металлы, зерно;
  - форекс: 10 пар, плюс золото и серебро;
  - 14 криптовалют.
- Админ добавляет и правит инструменты в **Панель → Инструменты**: спецификация, плечо, спред, комиссия, сессия, коды источников.
- **Источники:**

  | Источник | Рынки | Ключ | Данные |
  |---|---|---|---|
  | Binance | крипта | не нужен | реальное время (WebSocket, при сбое REST) |
  | Finnhub | акции США, форекс | бесплатный, finnhub.io | реальное время (до 50 символов) |
  | Yahoo Finance | всё остальное и история свечей | не нужен | неофициально, бывает задержка 10–15 мин |
  | Twelve Data | все рынки | платный | одним ключом |
  | Симуляция | — | — | если ничего не доступно |

- Источник выбирается для каждой категории в **Панель → Котировки**, там же ключи и состояние подключений. Если источник молчит 3 минуты, инструмент сам переходит на Yahoo, а затем на симуляцию. В терминале у такого инструмента появляется метка **SIM**, у данных Yahoo — метка **D**.
- Учитываются торговые сессии: NYSE, Европа, Лондон, Токио, CME, форекс 24/5, крипта 24/7. Когда рынок закрыт, рыночные сделки недоступны, а отложенные ордера срабатывают после открытия.

### Терминал (`/app`)
- **Обзор рынка:** Bid/Ask, изменение за день, избранное, поиск, статус рынка.
- **График:**
  - таймфреймы M1–D1;
  - свечи, бары или линия;
  - индикаторы SMA, EMA, Bollinger, объём, RSI и MACD (в отдельных панелях);
  - горизонтальные уровни;
  - на графике видны линии позиций, SL/TP и ордеров.
- **Ордера:** рыночный, Buy/Sell Limit, Buy/Sell Stop, Buy/Sell Stop Limit. Можно задать срок действия: до отмены, до конца дня или дату.
- **Позиции:** SL, TP, трейлинг-стоп, изменение стопов, частичное закрытие, разворот, закрыть все / прибыльные / убыточные / по символу.
- **Счёт как в MT5:** баланс, эквити, маржа, свободная маржа, уровень маржи. Кредитное плечо счёта выбирается от 1:1 до максимума, который задал админ. Есть маржин-колл и стоп-аут (закрывается самая убыточная позиция) и защита от отрицательного баланса.
- Объём в лотах. Стоимость пункта, маржа и комиссия считаются с пересчётом валюты котировки в доллары.
- Вкладки: история сделок и ордеров с итогами, операции по счёту, журнал.

### Роботы (`/bots`), аналог советников MT5
- Свой код на JavaScript в редакторе с подсветкой. Справка по API встроена в страницу, есть 4 шаблона: MA, RSI, пробой канала, пустой.
- События `onInit`, `onBar`, `onTick`, `onStop`. Торговые функции: `buy`, `sell`, все отложенные ордера, `close`, `modify`, `cancel`.
- Индикаторы `ta.*`: sma, ema, rsi, macd, bb, atr, highest, lowest, пересечения.
- Параметры `input()` редактируются без правки кода. Объект `state` сохраняется между перезапусками.
- **Лимиты пользователя** сервер проверяет для каждого действия робота:
  - макс. объём сделки;
  - макс. число позиций и общий объём;
  - дневной лимит убытка (робот останавливается);
  - макс. просадка от эквити на старте (робот останавливается);
  - макс. сделок в день и макс. плечо;
  - обязательный стоп-лосс;
  - дни и часы торговли с часовым поясом;
  - закрывать ли позиции при остановке.
- **Тестер стратегий:** до 5000 баров истории, спред и комиссия, стопы по максимуму и минимуму бара. Показывает статистику (прибыль, профит-фактор, просадку, процент прибыльных), график эквити, сделки и журнал.
- **Безопасность:** код выполняется в изолированной песочнице V8 (isolated-vm): 32 МБ памяти, 250 мс на вызов, без доступа к файлам, сети и серверу. Робот торгует только своим инструментом и видит только свои позиции. После 5 ошибок подряд робот останавливается. Журнал хранит до 2000 записей на робота.
- После перезапуска сервера роботы запускаются снова.

### Регистрация, менторы, админка
- Регистрация с кодом ментора или по ссылке `/?invite=КОД`, обязательное согласие с условиями демо-счёта.
- **Ментор** видит своих учеников (счёт, позиции, ордера, сделки, роботы, их код и журналы), может остановить робота ученика и сбросить ему счёт.
- **Админ** может:
  - начислять и списывать виртуальный баланс; эти операции видны ученику и не считаются торговой прибылью;
  - менять роли, плечо, ментора, блокировать пользователей;
  - создавать пользователей;
  - управлять инструментами и источниками котировок;
  - смотреть всех роботов;
  - настраивать стартовый баланс, плечо по умолчанию и максимальное, маржин-колл и стоп-аут, регистрацию, включение роботов и их лимит на пользователя.

## Установка на Linux (Ubuntu/Debian, например LXC на Proxmox)

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs build-essential python3

mkdir -p /opt/tradelab && cd /opt/tradelab
# распакуйте сюда архив
npm install --omit=dev
cp .env.example .env && nano .env        # админ и (по желанию) ключ Finnhub

npm i -g pm2
pm2 start server.js --name tradelab --node-args="--no-node-snapshot"
pm2 save && pm2 startup
```

Флаг `--no-node-snapshot` обязателен для песочницы роботов на Node 20 и новее.

Создать или восстановить админа:
```bash
node server.js create-admin you@mail.com НовыйПароль123 "Ваше имя"
```

### nginx + HTTPS
```nginx
server {
    server_name demo.example.com;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
Затем выполните `certbot --nginx -d demo.example.com`.

## Установка на Windows Server
1. Установите Node.js 22 LTS. При установке отметьте «Tools for Native Modules»: это нужно для `isolated-vm` и `better-sqlite3`, если для вашей версии нет готовой сборки.
2. Распакуйте архив в `C:\tradelab` и выполните там `npm install --omit=dev`.
3. Скопируйте `.env.example` в `.env`. Без nginx укажите `HOST=0.0.0.0` и откройте порт в брандмауэре.
4. Запуск: `npm start`. Для автозапуска выполните `npm i -g pm2 pm2-windows-startup`, затем `pm2 start server.js --name tradelab --node-args="--no-node-snapshot"`, `pm2 save` и `pm2-startup install`.

## Первые шаги после запуска
1. Войдите под админом и откройте **Панель → Котировки**. Вставьте бесплатный ключ Finnhub, чтобы акции США и форекс шли в реальном времени, и нажмите «Сохранить и переподключить». В таблице «Состояние» должна появиться связь.
2. Если сервер не может достучаться до Binance, укажите в `.env` альтернативные адреса `data-api.binance.vision` и `data-stream.binance.vision`.
3. **Панель → Настройки:** стартовый баланс, плечо, стоп-аут, роботы.

## Данные и резервные копии
Вся база хранится в одном файле `data/platform.db` (SQLite). Для бэкапа скопируйте папку `data/` при остановленном сервере или выполните `sqlite3 data/platform.db ".backup backup.db"`.

Если у вас стоит первая версия, база несовместима. Удалите папку `data/` перед запуском второй версии.

## Ограничения
- Свопы (перенос позиции через ночь) не начисляются.
- Данные Yahoo неофициальные и могут идти с задержкой. Для живых котировок по фьючерсам и индексам нужен платный источник (Twelve Data).
- В тестере пересчёт валюты идёт по текущему курсу, а не историческому.
